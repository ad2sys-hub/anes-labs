# ANES Labs

Labs publics, reproductibles et auditables de l'écosystème ANES, catalogués par
[ÉCHO DU FUTUR](https://echo-du-futur.lovable.app).

## Modèle canonique

- **Demo Capsule / Lab Capsule** = unité de Lab/test public → *Demo Capsule = Lab Test Unit*
- **Production Capsule ANES** = **NON déployée** tant que le produit n'est pas prêt
- **Lab** = environnement/scénario reproductible qui met en scène une Demo Capsule

Maturité : `CONCEPT → DEMO CAPSULE / LAB → REPOSITORY → TESTABLE PREVIEW → FORMATIONROOM → PRODUCTION MODULE/CAPSULE`
